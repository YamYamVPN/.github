## Modern Connection Technologies

YamYam VPN uses and supports modern connection technologies designed for flexible connectivity across different networks.

### VLESS

VLESS is a lightweight protocol commonly used with modern proxy and tunneling systems.

YamYam VPN uses VLESS-based connections in supported connection modes.

### Reality

Reality is designed to provide modern transport behavior while reducing dependence on traditional TLS certificate configurations.

### XHTTP

XHTTP is another modern transport option that can be useful across different network environments.

The available connection technologies may vary depending on the YamYam VPN version, network conditions, and server configuration.

## Split Tunneling on Android

YamYam VPN includes **split tunneling**, allowing users to control which applications use the VPN connection.

This can be useful when you want:

- selected apps to use the VPN;
- other apps to use the normal internet connection;
- better control over bandwidth usage;
- different routing behavior for different Android applications.
